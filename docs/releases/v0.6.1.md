# ccr 0.6.1 — update in place

Released 2026-10-13 · [CHANGELOG](../../CHANGELOG.md#061---2026-10-13) · [compare](https://github.com/kylinfish/claude-code-resume/compare/v0.6.0...v0.6.1)

`install.sh` links `ccr` to your clone, so new releases only arrive when the
clone is updated. This release makes that one command.

## Highlights

- **`ccr --update`** (or `ccc --update`) follows the installed symlink to your
  clone, runs `git pull --ff-only`, and prints what changed:

  ```
  → git -C ~/code/claude-code-resume pull --ff-only
  ✔ ccr 0.6.1 → 0.7.0. What changed:
  ## [0.7.0] - …
  ```

  Already current? It says so. If the copy isn't a git checkout, or the pull
  fails (for example because of local changes), it explains what to do and
  exits 1.

## Upgrading from 0.6.0 or older

Update by hand once — `--update` exists from this version on:

```sh
cd claude-code-resume && git pull
```

# ccr 0.6.1：一行指令更新

發布日期 2026-10-13

`install.sh` 是把 `ccr` 連結到你 clone 下來的目錄，所以只有那份 clone 更新了，新版才會生效。
這一版把更新變成一行指令。

## 重點

- **`ccr --update`**（或 `ccc --update`）：沿著安裝的 symlink 找到你的 clone，執行
  `git pull --ff-only`，並列出這次更新的內容。已經是最新版會直接說明；如果不是 git 安裝，
  或 pull 失敗（例如有本機修改），會說明原因與處理方式，並以錯誤碼 1 結束。

## 從 0.6.0 或更舊的版本升級

先手動更新一次，之後就能用 `--update`：

```sh
cd claude-code-resume && git pull
```
