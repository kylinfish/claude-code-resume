# ccr 0.2.0 — sessions beyond the CLI

Released 2026-10-01 · [CHANGELOG](../../CHANGELOG.md#020---2026-10-01) · [compare](https://github.com/kylinfish/claude-code-resume/compare/v0.1.0...v0.2.0)

`ccr` used to show only the transcripts that were still in `~/.claude/projects`.
This release finds the sessions you were missing and explains where the rest went.

## Highlights

- **Claude Desktop (Cowork) sessions** are listed in magenta as `Desktop · <folder>`.
  Picking one resumes its transcript in the CLI with `--fork-session`, so the new
  conversation becomes a normal CLI session and Desktop's copy is never written to.
- **Expired sessions.** Claude Code deletes transcripts idle for `cleanupPeriodDays`
  (30 days by default). `Ctrl-X` or `ccr --expired` lists the sessions that only
  survive in `~/.claude/history.jsonl`, greyed out with their first prompt, so you
  can see what a conversation was about even though it can no longer be resumed.
- **Retention warning.** The menu header warns when `cleanupPeriodDays` is unset or
  below 90 days. To keep sessions for a year, add `"cleanupPeriodDays": 365` to
  `~/.claude/settings.json`.
- **Your names first.** Titles prefer the name set with `/rename` or `claude -n`.
- **Fork.** `Ctrl-F` in the menu, or `--fork` on the command line, resumes into a new
  session id and leaves the original untouched.
- **`--version`.**

## Upgrade notes

- `--last` / `-n N` only pick CLI sessions, never Desktop or expired ones.
- The index cache is now `~/.cache/ccr/index-v2-*.json`; the first run rebuilds it.
- New environment variables: `CCR_DESKTOP_DIR`, `CCR_HISTORY_FILE`.

# ccr 0.2.0：不只 CLI 的 session

發布日期 2026-10-01

以前 `ccr` 只看得到還留在 `~/.claude/projects` 的對話紀錄。這一版把漏掉的 session 找回來，
也說明其他的去了哪裡。

## 重點

- **Claude Desktop（Cowork）對話**以洋紅色 `Desktop · <資料夾>` 列出。選定後以 `--fork-session`
  在 CLI 開啟，新對話存成一般 CLI session，Desktop 裡的原檔不會被寫入。
- **已清理的 session**：Claude Code 會刪除超過 `cleanupPeriodDays`（預設 30 天）沒活動的對話。
  `Ctrl-X` 或 `ccr --expired` 會以灰色列出只剩 `~/.claude/history.jsonl` 紀錄的 session 與第一句
  prompt，雖然無法 resume，但能知道那段對話在做什麼。
- **保留天數提醒**：`cleanupPeriodDays` 沒設定或小於 90 天時，選單標頭會提醒。想保留一年，
  在 `~/.claude/settings.json` 加上 `"cleanupPeriodDays": 365`。
- **你取的名字優先**：標題優先使用 `/rename` 或 `claude -n` 設定的名字。
- **分支續接**：選單按 `Ctrl-F`，或指令加 `--fork`，以新的 session id 續接，原對話不受影響。
- **`--version`**。

## 升級注意

- `--last`／`-n N` 只會挑 CLI session，不會選到 Desktop 或已清理的 session。
- 索引快取改為 `~/.cache/ccr/index-v2-*.json`，第一次執行會重建。
- 新增環境變數：`CCR_DESKTOP_DIR`、`CCR_HISTORY_FILE`。
