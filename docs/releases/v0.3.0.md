# ccr 0.3.0 — see what your sessions left running

Released 2026-10-01 · [CHANGELOG](../../CHANGELOG.md#030---2026-10-01) · [compare](https://github.com/kylinfish/claude-code-resume/compare/v0.2.0...v0.3.0)

Agents often start a dev server or a watcher to demo their work and leave it
running. This release shows them before you resume, so you know what is still
using CPU, memory and ports.

## Highlights

- **Process pane.** A pane above the session list shows what is still running under
  any listed session's project, busiest first:

  ```
  ⚙ processes running under your session projects (by CPU)
    :5173   PID 4242    12.5% CPU   200 MB  vite                        ~/code/acme-api  → http://localhost:5173
    -       PID 6060     1.0% CPU    80 MB  tsc --watch                 ~/code/acme-api
  ```

  It lists listening ports (with a `http://localhost:<port>` link) and known dev
  commands / watchers such as vite, next, tsc, nodemon and python, with CPU, memory
  and the project they belong to.
- **Highlighted.** Port in yellow, command in bright white, project in cyan, link in
  green, and CPU in red once a process is at 50% or more.
- **`⚙` marks** on sessions that have something running, and the list is printed
  again just before a session resumes.
- **Low noise.** Shells, `claude` itself and the MCP servers it starts are skipped,
  one row is kept per process tree (port holders first), and `$HOME` / `/` never
  count as a project.

## Notes

- Uses `ps` and `lsof` (both built into macOS), cached for 5 seconds. Without `lsof`
  the pane shows that nothing was detected and everything else works as before.
- The pane is taken when the menu opens; reopen `ccr` to refresh it.

# ccr 0.3.0：看見 session 留在背景的 process

發布日期 2026-10-01

agent 常會開一個 dev server 或 watcher 來 demo，結束後就留在背景。這一版在 resume 之前就把它們列出來，
讓你知道還有哪些東西在佔用 CPU、記憶體和 port。

## 重點

- **Process 區**：列表上方獨立一區，依 CPU 排序列出所有 session 專案底下還在跑的 process：
  listen 中的 port（附 `http://localhost:<port>`）以及 vite、next、tsc、nodemon、python 這類開發指令與
  watcher，含 CPU、記憶體與所屬專案。
- **高亮**：port 黃色、指令亮白、專案青色、連結綠色，CPU 達 50% 以上顯示紅色。
- **`⚙` 標記**：有 process 的 session 會標 `⚙`，resume 前也會再印一次清單。
- **不列雜訊**：不列 shell、`claude` 本身與它啟動的 MCP server；同一個 process tree 只留一筆，
  有 port 的優先；`$HOME` 與 `/` 不算專案目錄。

## 注意

- 使用 macOS 內建的 `ps` 與 `lsof`，結果快取 5 秒。沒有 `lsof` 時 process 區會顯示沒有偵測到，其他功能照常。
- process 區是在選單打開時取得的，要更新請重新執行 `ccr`。
